# 検証記録

分析ごとに、データソース、結果、予想モデルへの採用判断を記録する。
再現性のため、保存先キャッシュ名も書く。

## 1. 市場情報（単勝オッズ・人気）
- 保存先: feature_analytics_cache / feature_interactions_cache
- 結果: 除外すると予測精度が落ちる（baseline loss 1.586 → 学習後 2.24）。含めても市場の写しになる。
- 採用: 不採用（市場情報は予想モデルの入力に使わない）
- 備考: 公開データのみでは市場を超えられない、を複数回確認済み

## 2. 枠番
- 保存先: frame_mechanism_cache / frame_by_popularity_cache / frame_by_odds_cache
- 結果:
  - 1〜3枠は実1着率が市場より低く、6〜8枠は高い（名古屋・園田など）
  - 人気帯別に統制しても同じ傾向（1人気枠8は枠1より実1着率+3.34pt）
  - オッズ1.5-3.0倍で枠効果が顕著、5倍以上では消える
  - 原因: 外枠に強い馬が入りやすい交絡 + 市場の系統誤差
- 採用: 採用（frame + 会場×距離帯×馬場別の枠番有利度）

## 3. 斤量

## 4. 性齢・年齢
- 保存先: age_analysis_cache
- 結果:
  - 性別は result_runners ベースで牡/牝/セの3値
  - 牡 +0.126、牝 -0.460（市場が牝を過大評価）、セ +0.188
  - 年齢別は4歳が-0.03で市場とほぼ一致。「4歳有利」の仮説は不支持
  - 4歳牡 +0.593（最大の優位）、4歳牝 -0.505（最大の劣位）
- 採用: 採用（性別 牡/牝/セ + 年齢 2〜12歳）
- 注意: runners.age_sex はセを牡と誤記、result_runners を使う

## 11. 馬×騎手の組み合わせ
- 保存先: horse_jockey_analysis_cache / horse_jockey_residual_cache
- 結果:
  - 乗り替わり -0.47（劣位）、継続騎乗 +0.77（優位）
  - 馬×騎手出走回数: 1走 -2.42、4走+ +0.63
  - 馬×騎手連対率 0.5+ は +9.58（交絡込み）
  - 馬効果と騎手効果を分離した残差:
    - 相性上位20% +5.51（実22.55% vs 市場17.04%）
    - 相性下位20% -3.78（実7.01% vs 市場10.79%）
    - 履歴なし（初コンビ） -1.73
    - 乗り替わり/継続騎乗に関わらず同じ傾向
- 解釈: 市場は馬単独・騎手単独は織り込むが、特定の組み合わせは織り込めない構造的盲点
- 採用: 採用（相性残差の分位 or 連続値）
- 注意（未解決）: 時系列分割の検証は未実施。学習データの残差で評価しているため、
  潜在的な情報漏洩の可能性あり。将来、2023年残差→2024年評価の時系列検証を推奨。

## 予想モデルへの採用特徴量（確定）

1. 枠番
   - frame（1〜8）
   - 会場×距離帯×馬場別の枠番有利度

2. 馬の状態
   - 斤量
   - 馬体重増減（細分化、保留中）
   - 性別（牡/牝/セ）
   - 年齢

3. 能力（絶対指標）
   - 通算勝率、連対率、3連対率
   - 平均着順、直近3走平均着順
   - 平均上3F、最速上3F
   - 平均タイム（1000m換算）、最速タイム

4. 条件適性
   - 同距離帯 連対率・平均着順
   - 同馬場 連対率
   - 同会場 連対率
   - 同芝ダート 連対率
   - 前走からの日数、長期休みフラグ

5. 騎手
   - 騎手ランク（通算勝率から5分位）
   - 馬×騎手 相性残差（分位 or 連続値）

6. 脚質
   - 脚質（逃げ/先行/差し/追込）
   - 脚質×枠番、脚質×距離帯、脚質×頭数

7. 交互作用として採用
   - 枠番 × 会場×距離帯×馬場
   - 性別 × 年齢
   - 騎手ランク × オッズ帯

## 不採用特徴量

- 単勝オッズ、人気、過去人気（市場情報）
- 頭数（単独）
- 距離・馬場・会場（単独）
- 騎手ID
- 減量印（単独・交互作用とも有意差なし）
- 血統
- 毛色、生年月日
